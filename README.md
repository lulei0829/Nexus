# Nexus 业务设计文档

版本：v0.1 · 整理日期：2026-11-04（America/Los_Angeles）

Nexus 当前处于业务设计与学习阶段。本仓库首次将「Nexus 学习」聊天中已经沟通、确认的规则整理成可查阅、可维护的文件。**本文档描述已确认的设计，不代表功能已经开发、上线或通过验收。**

## 阅读入口

| 文件 | 读者与用途 |
|---|---|
| [商户与分销商系统规则及业务流程](docs/merchant-distributor-guide.md) | 商户、分销商：了解合作关系、权限、选品、订单、结算与售后 |
| [首期范围与已确认参数](docs/phase-one-scope.md) | 产品、运营、开发：核对首期边界与设计目标 |
| [待确认事项与历史修订](docs/open-questions-and-revisions.md) | 继续设计时使用，避免把提案或旧口径当作最终规则 |
| [规则来源索引](docs/decision-sources.md) | 按原聊天轮次追溯关键确认 |

## 使用约定

- 依据原聊天的时间顺序整理，后续明确更正覆盖早期口径。
- 没有得到明确确认的提案、尚未细化的金额和规则，集中列在待确认文件。
- 文中的金额示例用于解释分配关系，不是订阅报价或正式收费承诺。
- 本次未生成完整数据库、接口规格、正式合同或会计政策；这些内容仍需在已确认业务基础上进一步设计。
- 文件保存到 GitHub 不等于发送给商户或授予新的共享权限；可见范围沿用仓库现有设置。
