# Nexus 首期范围与已确认参数

版本 v0.1 · 2026-11-04 · 设计阶段

本文件汇总「Nexus 学习」中已确认的范围和目标。数字是设计基线或拟验收要求，不是现有系统性能报告。

## 一、首期交付范围

四端网页系统：商户端（含分销商业务）、主控端、工厂端、创作者中心。支持桌面和平板，中文、英文、西班牙文。手机 App 后续开发。

首期完整覆盖普通商品订单、预先创建的定制商品、模板个性化、按主控授权的全动态定制、售后退款和补发；包含可生产数量、库存预留、开工扣减、质检不合格与内部补产。

支持 DTG、DTF、固定模板热升华。Nexus 负责实际尺寸生产图稿、任务资料及校验，工厂软件负责设备格式与机器执行；工厂维护并确认生产模板，系统保存版本。UV、激光、刺绣、全幅裁片等专项工艺后续适配。

提供商户、分销商及工厂 API，工厂 ERP 可回传生产进度和可生产数量，经与网页一致的校验后生效。超期订单的继续履行首期只允许网页确认。

外部平台范围：Temu、TikTok Shop、Shopify、Etsy；首批 TEMU LOCAL 优先联调，SEMI 单独适配，Shopify 优先验证全动态，平台权限与可取得字段以联调为准。Nexus 不负责自动向外部销售平台上架商品。

首期无旧系统业务与账务迁移，从零初始化、建账。完整开发设计需后续完成并确认，再进入编码；本套业务文件不是完整工程规格。

## 二、已移出或暂不开放的范围

- 备货生产、厂区成品库存及相关调拨仓储：历史上曾讨论并确认部分规则，后续已整体移出首期，不在本期启用。
- 历史库分层、自动归档、保留期限和自动清理：后续专题。早期三个月归档、三年保留不作为首期执行政策。
- 首次分配时把一张订单拆给多个不同工厂主体。客服异常改派仍保留。
- Nexus 与商户自行供货商品混合履约、自动删单行。
- 所有商品强制逐件唯一编号；后续按需扩展。
- 买家直接上传定制资料页面。
- 退货回收、换货、维修处理方式。
- 首期全自动银行接口付款；仅预留 BOA 在线 ACH、PayPal 接口。
- 手机 App 及其通知；首期提供网页、邮件、业务待办。

## 三、业务默认值与责任归属

| 参数或规则 | 已确认口径 |
|---|---|
| 主体有效账号默认名额 | 2，包含首个主账号；主控可调整，跨端同一账号不重复占名额 |
| 分销层级 | 两级，一个有效上级，不能发展下级或更换上级 |
| 工厂自动接单 | 可配置，默认关闭 |
| 自动开工等待 | 默认 30 分钟，全计划完成排产后计时；非生产时间顺延，暂停计划不能开工 |
| 发货提醒 | 工厂接单起默认 72 个自然小时仍有未发货数量；主控配置规则 |
| 接单超时提醒 | 正式分配起算，时长由主控配置，未确认统一默认值 |
| 自动发货 | 质检包装完毕后的下一个工作日结束；须有完整物流资料 |
| 自动签收 | 正常包裹交运起默认 30 天；明确异常不适用 |
| 全动态履约 | 订单日期起默认 14 个自然日完成全单质检包装；可配置 |
| 信用账期 | 默认 7 天，洛杉矶自然日，首次欠款当天第 1 天 |
| 欠费提示 | 工厂质检、发货环节，默认每个商户每天 2 次，工厂可配置 |
| 工厂评级 | 优、良、中、差，用户已设四档、每档 40 分；详细评分规则待定 |
| “差”级接单 | 不接新生产订单；已接订单继续履行。历史成品库存发货例外属于后续备货范围 |
| 跨厂区 | 商户及工厂均获预授权，并满足资格、库存、模板和用户费用条件 |
| 月费 | 预付、可余额自动扣缴；停用仍累计，正式终止后停止新增，历史欠费补缴 |
| 月度对账 | 洛杉矶自然月，PDF 汇总；不是正式发票 |

“每档 40 分”沿用用户表述，没有据此自行制定总分、分界值、加扣分细则。评级展示按商户账号由主控授权。

## 四、文件与图片

| 文件或功能 | 上限或要求 |
|---|---|
| JPG / JPEG / PNG | 单文件 12MB |
| PDF | 单文件 50MB |
| SVG | 单文件 10MB |
| STL / GLB | 各单文件 50MB，用于 3D 展示，不表示已支持 3D 打印履约 |
| 网页 3D 预览 | 5–10MB 优化目标，原文件单独保留 |
| 每条明细定制图片 | 最多 6 张，绑定前、后、左、右、上、下；受商品适用与必填位置约束 |
| 沟通凭证图片 | JPG / JPEG / PNG，单张 12MB，独立于六张定制图 |
| 图片生产校验 | 位置、比例、实际印制尺寸及清晰度；工厂按商品与工艺设要求 |

文件生成时限、像素与复杂度上限、真实模型及工厂软件兼容指标仍待验收设计。

## 五、容量、性能及恢复目标

| 指标 | 已确认设计目标 |
|---|---|
| 自动同步店铺 | 首期各平台合计 10 家 |
| 高峰日订单 | 5,000 笔销售订单 |
| 单批同步或导入 | 1,000 笔 |
| 订单明细 | 平均 3 条，每单最多 50 条 |
| 全动态高峰 | 500 单/日 |
| 新订单同步 | 平台可读取且符合条件时，正常运行、接口授权正常的条件下 10 分钟内进入待处理列表 |
| 导入校验与商品匹配 | 完整接收后 1,000 笔 10 分钟；资料完整且已有对应关系，与同步分别计时 |
| 同步连续失败告警 | 默认 30 分钟，主控可配置；授权失效或权限缺失立即通知所属账号 |
| 扫码 | 10 厂区，每厂区最多 5 台，合计 50 台并发 |
| 其他网页并发 | 50 人，与扫码、批量导入、图片处理混合负载验证 |
| 在线扫码响应 | 约定设备与网络下至少 95% 在 2 秒内返回业务校验及保存结果 |
| 核心服务 | 7×24，月度可用性目标 99.9%，维护影响单列 |
| 恢复目标 | RTO 30 分钟；RPO 0，覆盖已确认保存的业务数据及图样附件 |

这些目标须通过开发后的真实负载测试、接口联调和恢复演练验证；本次未执行系统性能测试，也未对架构能否满足目标作实现承诺。
