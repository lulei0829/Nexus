# Nexus 商户与分销商系统规则及业务流程说明

版本：v0.1  
整理日期：2026-11-04（洛杉矶时间）  
适用范围：已确认的首期业务设计  
资料来源：「Nexus 学习」聊天，详见[规则来源索引](decision-sources.md)。

> Nexus 尚处于设计阶段。以下是已确认、拟用于系统开发和业务沟通的规则，不是已上线功能清单。套餐金额、取消费用、售后期限等未定细节见[待确认事项](open-questions-and-revisions.md)。

## 1. 各方是什么关系

| 参与方 | 主要职责 |
|---|---|
| Nexus 运营方 POL | 提供平台服务，管理入驻、规则、资金结算、客服争议和系统运营 |
| 主商户 | 自营业务、选品、设定下属分销商的可选商品与分销价格，管理分销合作和信用责任 |
| 分销商 | 在上级授权范围内选品、定制，管理自己的店铺、订单、人员、钱包和售后 |
| 工厂及厂区 | 提供商品和生产能力，承接、生产、质检、包装、供货与交付 |
| 创作者 | 提供作品或设计，并按授权规则获得版权收入 |
| 终端买家 | 通过商户或分销商的外部销售平台下单，不作为 Nexus 商户账号管理对象 |

主商户与分销商是**两级关系**：一个主商户可以有多个分销商；一个分销业务账号只能有一个有效上级，不能继续发展下级，不能更换上级。

分销商可以是同一主体内部的业务渠道，也可以属于独立主体。**独立主商户身份与其他主商户下的分销身份，按真实主体双向互斥**，不能用另开账号或调整注册顺序绕过。同主体内部渠道不因此被禁止。

工厂承担商品供货和交付责任，主商户不作为向独立分销商供货的卖方。已确认的合同关系为：

| 关系 | 对应主体 |
|---|---|
| 普通生产供货 | 下单主商户真实主体与承接工厂 |
| 独立分销商生产供货 | 下单分销商真实主体与承接工厂 |
| 分销合作 | 主商户与独立分销商，约定合作、收益及信用责任 |
| 平台服务 | Nexus 运营方与各参与主体 |

内部渠道由所属真实主体作为合同当事人。在预先接受的交易条款下，工厂正式接单是具体生产订单合同成立的系统记录节点；人工接单与授权的自动接单都保留证据。主商户所得差额属于约定的分销合作收益，不能仅凭差额认定为商品转售收入。Nexus 对账单也不等于正式发票。

## 2. 如何入驻和建立分销关系

主商户预登记企业名称、邮箱和联系人，系统生成随机邀请码与邀请链接。分销方通过链接或邀请码核对上级，完成注册并提交或确认主体资料；经主控审核后关系生效。预登记本身不代表分销商已经加入。

主商户和分销商注册时均需同意系统使用条款，包括版权、数据归属及隐私条款，并保留接受记录。

审核通过前，可以选品、绑定店铺、同步订单；不能充值、提现或提交生产。通过审核后，具体业务还受订阅状态、信用、功能开关和人员权限限制。

## 3. 谁能看、谁能操作

权限同时检查当前业务账号、岗位、页面、按钮和数据范围。岗位授予权限，账号可关联多个岗位；多岗位合并不能将某渠道的操作权扩展到另一渠道。

- 主商户可以在获准范围内汇总查看下属订单和账单。
- 分销商只查看自己有权限的业务，不能查看其他分销商的数据。
- 主商户与分销商分别管理自己的岗位和员工。上级查看业务不等于可以代管下级员工。
- 同一登录账号在主商户与分销商任职时，由双方分别授权，操作记录保留当前业务身份。
- 页面访问权是按钮操作权的前提；撤销页面权时同时撤销对应按钮权，重新授权页面不会自动恢复旧按钮权。
- 分销商不能查看工厂结算价或主商户分销收益；页面、API、导出和 PDF 对账单执行同样限制。
- 主商户**不能代分销商提交生产订单**，网页及 API 均受限。分销商使用自己的自动提交配置，或由自己的授权人员提交。

主商户可以暂停下属分销商的新订单下单权限。暂停期间继续同步订单，保留待下单状态，不冻结资金、不预留库存；已经正式分配的订单不因这项管理暂停而中断。信用逾期等其他限制另行判断。

## 4. 选品、设计与价格

### 4.1 商品和编码

工厂维护标准商品，商品审核和具体厂区生产资格由主控管理。工厂及参与厂区须位于美国或加拿大。

- Model No. 表示商品型号；颜色、尺码使用独立标准 SKU。
- 直接选用标准商品时，沿用标准 SKU。
- 在标准商品上应用图样形成固定定制商品时，生成所属业务账号的 Nexus SKU。
- 不同账号自行创建的定制商品分别拥有 Nexus SKU；同一主商户内授权迁移可共用已有 SKU，见第 5 节。
- 销售编码按“商户或分销业务账号＋销售编码”管理。普通模式下，一个销售编码固定对应一个商品；多个销售编码可指向同一商品。
- 固定设计更换图样时，使用新的销售编码和 Nexus SKU，旧记录保留。
- 核心材质、版型等规格变化需新建 Model No. 及 SKU、重新审核；同型号新增颜色、尺码则新增 SKU。

分销商可选标准商品由上级主商户选定并设置分销价；分销商可在此基础上创建定制商品，按分销价加适用版权费结算。

### 4.2 作品授权与定制资料

使用创作者作品前申请授权，默认人工审批。创作者可主动开启条件自动授权；全部条件满足且申请方接受对应版本条款后生效，否则进入人工协商。

商户使用自有图样的路径是：所属主体开通创作者中心身份，上传作品，再按审核及授权规则在商户端应用。一个商品可以组合多个作品、多个创作者，分别检查授权和计费。

首期提供网页设计编辑器，位置、尺寸及工艺受工厂获批模板限制。在获批定制范围内，这些差异不改变工厂加工费用；作品版权费单独按授权计算。公共字体由主控管理，品牌字体需提交授权资料并审核，模板保留字体版本。

按件收费的版权费以“作品＋实际结算商品单位数量”计量。同一作品在同一件商品多处使用只计一次；同一件使用多个收费作品，分别累加。次品重做和原设计售后补发不重复计版权费。

授权到期后不能用于新匹配订单；到期前已匹配并锁定费用的订单，可完成原约定生产、发货和原设计售后补发。调价或缩小范围形成新授权版本，经被授权方确认后作用于后续未锁费订单。提前终止须由主控依据条款及争议结果处理，创作者提交申请不立即撤销既有授权。

### 4.3 全动态与模板个性化

模板个性化按订单保存姓名、照片等参数，不因每单参数不同而改写模板 SKU。全动态是主控按业务账号另行开放的模式：销售编码固定关联基础标准 SKU，再按最终设计生成或复用 Nexus SKU。生成 SKU 不等于提交生产或开工。

原始销售订单及数量锁定，不被后续同步覆盖。允许补齐缺失资料；对校验不合格图片，所属商户或分销商可按限定例外更新，保留原图、版本、原因、操作人与时间，填写客户确认声明及说明，并重新校验。客户沟通图片可作凭证，单独保存，不占定制图样位置；原始文字不能擅自改写。

每条明细最多六张定制图，对应前、后、左、右、上、下；适用和必填位置由商品配置。缺图、比例不符、清晰度不够时整单暂停，不能自动裁剪、更改买家内容或用不合格文件生产。预览是否必须人工确认，由所属账号设置。首期不提供终端买家直接上传页面，资料来自销售平台或商户、分销商上传。

### 4.4 价格和调价

工厂结算价及分销价按未税价维护，税费单列。平台内生产、分销交易税费由 Nexus 处理；终端销售税由销售平台或商户负责。转售免税证明提交主控审核，按获批范围及有效期适用。

商品入单即完成匹配的，按首次进入 Nexus 时的价格锁定；入单未匹配的，补齐匹配时确定价格。后续调价不重算已锁定订单。

工厂提价需商户确认；分销订单由主商户确认。未确认时相关新订单暂停分配，也不能转其他工厂绕开。主商户接受工厂提价后，分销价不自动提高；是否要求分销商确认提高分销价，由主商户参数控制。允许主商户承担低于工厂价的分销差额，但仍须通过资金与共享信用检查。

报价是否包含跨境费用由工厂明确，未包含部分向订单所属账号单列；换厂产生的新费用及差额需用户确认。

## 5. 店铺绑定、同步和迁移

计划接入 Temu、TikTok Shop、Shopify、Etsy。首批联调优先 TEMU 与 Shopify，具体接口权限和平台要求需联调验证。

同一家销售店铺只能绑定一个商户或分销业务账号。订单按来源平台、店铺身份和平台原始订单 ID 去重；不同店铺同号订单独立，重复同步不产生新订单。

首次绑定默认只自动同步绑定成功后创建、符合条件的新订单；此前待生产订单由所属账号手动导入。同步条件按店铺配置，默认已付款、未取消、整单尚未发货。

同步与生产提交是两个动作：所属商户或分销商分别设置自动或人工提交，全部业务检查通过后才能正式分配。

店铺仅允许在**同一主商户体系**内，由主商户授权，在自营与分销账户之间或分销账户之间迁移；禁止跨主商户迁移，解绑重绑也不能绕开。

迁移时原账号余额不得为负。原账号存在未完成订单或冻结资金不影响解绑，历史订单、资金、账单、售后继续由原账号处理。新进入的订单归新账号；旧订单再次同步仍识别为旧单。

经授权可沿用销售编码对应关系及已有 Nexus SKU；原账号其他店铺可继续获准使用，各账号业务及资金仍独立。**作品授权必须按接收主体和业务账号重新校验覆盖情况**：同属一个主商户不代表自动继承版权授权。未覆盖时保留对应关系，相关新订单整单暂停生产流转，待补齐授权。

## 6. 从销售订单到生产交付

~~~mermaid
flowchart TD
  A[平台同步或手动导入] --> B[去重并保存原始订单]
  B --> C[整单商品、资料、作品授权及价格检查]
  C -->|不通过| D[暂停并通知所属商户或分销商]
  D -->|补齐后重新校验| C
  C -->|通过| E[按所属账号设置自动或人工提交]
  E --> F[资金、信用、订阅、工厂资格及分配条件检查]
  F -->|不通过| D
  F -->|通过| G[正式分配：冻结资金、预占信用、预留可生产数量]
  G --> H[工厂接单]
  H --> I[生产文件全部就绪并校验]
  I --> J[排产与开工]
  J --> K[生产、质检、包装]
  K --> L[按包裹发货并结算]
  L --> M[全部有效包裹签收后履约完成]
~~~

### 6.1 整单完整性

首期进入 Nexus 的订单默认全部由 Nexus 履约。任一明细未匹配、必要资料未齐或存在不合格内容，整单暂停。不能自动删明细、减数量、拆出商户自行供货商品，或将缺失 Nexus SKU 的动态商品当普通标准商品生产。

首期不支持一单混合 Nexus 商品与商户自行供货商品，也不支持首次分配时拆给多家不同工厂主体。异常改派是另一流程。

### 6.2 工厂分配与库存

主控管理分配规则；商户提供履约要求及指定工厂条件。候选厂区须同时具备有效商品承接资格、生产线、足够的可生产数量和符合订单设计要求的有效模板，不能为适配工厂改变既定设计。

常规由同一工厂主体承接整单。同一工厂的多厂区，在主控预先允许商户账号与工厂账号跨厂区，且满足包裹、面单及费用条件时可自动安排，无需逐单审批。不能先拆厂区再强制商户追加面单或费用。尚未接单数量可在同工厂合格厂区间重分，并通知相关各方。

库存是“厂区＋标准 SKU”的可生产数量，不是原材料 BOM 明细账。正式分配预留全部所需数量；开工才扣减数量并释放对应预留，完成或发货不重复扣减。不同定制 SKU 可共用其基础标准 SKU 的可生产数量。

### 6.3 接单、排产和生产

工厂接单可人工、ERP 或按配置自动完成，自动接单默认关闭。生产主线为：

**接收订单 → 安排生产计划 → 生产中 → 生产完毕 → 质检包装完毕 → 已发货。**

生产文件全部就绪并通过校验后才能排产；全部计划数量安排到生产线后启动默认 30 分钟开工计时，到期且处于厂区生产时间才自动开工，非生产时间顺延。提前质检或打包扫描可按既定规则触发计划开工并扣减尚未扣减的全部计划数量；暂停中的计划不能靠扫码绕过限制。

一份生产订单可有多个厂区计划，批次与计划允许多对多，但不能改变原订单商品及数量。工厂提供预计发货时间；商户或分销商维护平台最晚发货规则，已计算截止时间不因后来改参数而变化。

因工厂生产原因导致不合格，返工或补产由工厂承担，不能增加原订单金额或订购数量。不合格数量复检合格前不得计入质检完成，也不能被整单确认覆盖。商户可按权限查看异常及处理进度。

### 6.4 包装、物流和完成

一个商户或分销账号的同一销售订单对应一张质检包装主单，多厂区、多计划、多次作业记录在明细。补发共用该主单但数量和进度独立统计，不增加原订单订购数量。

质检按订单核对，打包按包裹核对；首期按订单明细、实际设计、SKU 和数量管理，不强制逐件唯一编号。

合包只限同一商户或分销业务账号，仍需符合该账号配置条件；同一主体的不同账号不能跨账号合包。包装方案及标签保留订单匹配时的版本。

包裹发货须有完整物流渠道与运单号。可手动确认；未手动确认时，在质检包装完毕后的下一个工作日结束时按规则自动认定发货。该时点物流资料仍缺失则不触发，之后补齐时立即触发，以实际触发时间记录交运。**系统自动认定是业务记录，不等同于承运商实际揽收凭证。**

各包裹独立发货、计时和结算。发货信息是否自动回传销售平台由所属账号配置。工厂在发货后不能直接修改运单资料。

全部有效包裹签收且无未处理物流异常后，订单履约完成。正常包裹默认交运满 30 天无签收更新时自动认定签收；丢失、退回、拒收和派送失败等明确异常不适用。

全动态订单默认从订单日期起 14 个自然日内完成全单质检包装，可配置。客户确认、更正资料和系统维护等待不自动顺延；超期保留状态并通知相关方，必须通知主控并生成待办。这是内部履约规则，不代表销售平台允许相同发货周期。

## 7. 钱包、结算与分销收益

### 7.1 独立核算与资金占用

每个业务账号独立记录余额、冻结、收入、退款、欠款和账单。同主体不同账号不会自动混用；有权限人员可主动在同一主体业务账号间转账，分别留流水，无需主控审核。不同主体间不能使用内部转账，即使存在分销上下级关系。

统一美元记账、结算、转账及提现；人民币到账按确认时有效汇率换成美元，保留原币和汇率记录。

首期外部充值与提现通过主控登记实际收付款结果，预留 BOA 在线 ACH 和 PayPal 接口，不视为已经接通线上支付。充值入账和人工账务调整须两名不同的主控人员分别登记、复核，通过后生效。

订单正式分配前优先使用下单账号自身可用余额，不足部分检查信用。分配时冻结现金、预占信用；发货时按包裹实际 SKU 和数量结算，未发货部分继续保持必要预占。

### 7.2 分销收益示例

以下均为美元，未计税费、系统服务费、尾程面单及其他单列费用：

| 项目 | 每件金额 |
|---|---:|
| 工厂生产结算价 | 10 |
| 主商户设定标准商品分销价 | 15 |
| 创作者版权费 | 1 |
| 分销商定制商品结算价 | 16 |
| 主商户分销合作收益 | 5 |

分销商的结算价为标准商品分销价加适用版权费。工厂生产收入、创作者版权收入还需按各自订阅计划扣收服务费，示例不是各方最终净收入。

自有资金正常结算时，按已确认发货规则入账。分销商用授信并仍欠款时，POL 垫付工厂 10 和创作者 1，主商户 5 记为待结算收益，不进入可提现余额。分销商欠款仍为 16，不能与 POL 本次垫付 11 混为一笔。

该分销商余额恢复至大于等于 0 后，释放对应的有效主商户待结算收益。退款时先冲减对应订单未结算收益，余款再按主控核定金额从钱包扣回，避免重复扣款。

### 7.3 提现和账单

主商户、分销商、工厂、创作者可由授权人员发起提现，只能使用未冻结可用余额。申请冻结资金，主控审核并安排实际付款；付款前再次检查，资金不足则暂停，成功记账，失败按规则释放冻结。

美元提现到业务账号绑定银行账户。已确认允许自行绑定、更换，不要求开户主体与注册主体一致，提现申请仍须审核。

运营方分别提供各方对账单，工厂厂区账单由所属工厂负责。可按自选区间查流水，每月按洛杉矶自然月生成 PDF 汇总；工厂、创作者仅展示自身收支。对账单不作为正式发票。

## 8. 共享信用和欠款责任

主控为主商户体系设置美元信用总额度，主商户与下属分销商共用。主商户还可以给每个分销商设使用上限，两个条件须同时满足。

**可用共享信用＝总额度－各账号实际负余额绝对值合计－未结算订单信用预占。**

正余额不会自动抵消其他账号欠款；预占转实际欠款时不能重复计算。退款或补发预计突破上限时，先解决资金或额度不足，再批准执行。

信用账期默认 7 天，从实际首次欠款当天起算，洛杉矶自然日当天算第 1 天；持续欠款期间新欠款不延长原到期日。整个体系从任一账号首次欠款时同步启动整体账期。

| 情况 | 影响 |
|---|---|
| 单个分销商逾期，整体尚未逾期且信用正常 | 暂停该分销商 |
| 主商户逾期 | 主商户及全部下属分销商暂停 |
| 整体到期仍有账号欠款 | 暂停整个体系，其他账号正余额不自动抵扣 |
| 存在实际欠款，金额达到或超过信用额度 | 立即按规则受限，不等待账期到期 |
| 额度为 0，且没有实际欠款 | 不因 0≥0 停用，可用自有资金 |

受限后必须还清相应欠款、余额恢复至大于等于 0，才能解除该欠款限制；仅还至低于额度不足以恢复。整体恢复要求相关账号均无负余额。主控允许下调额度至低于已有占用，按欠费规则处理，不重置账期。

信用受限账号仅保留充值和账单功能，后台继续同步订单但不提交生产。已开工数量可继续履行；未开工数量暂停并释放对应库存预留、未结算现金冻结和信用预占。已结算款不冲回。恢复后重新校验、预留并由工厂重新排产，不能直接自动开工。

尚未提交生产、已超过交期的积压订单，须所属商户或分销商授权人员在网页确认继续履行，再重新检查；首期 API 无此确认或强制放行能力。

**主商户承担下属分销商欠款的偿还责任，包括分属不同主体的分销商。**代偿需人工介入、按可配置时长提前告知；记录主商户代偿应收、分销商代偿应还，并关联原债务。已偿还 Nexus 部分释放原信用占用，分销商欠主商户的代偿款单独记账，不再占 Nexus 信用上限。主商户自行配置是否自动归还代偿款。

同一主体商户向自己的工厂下单，已确认允许 POL 授信垫付，欠款仍归下单商户并单独记录主体关联。商户逾期后，主控可按约通知，用同主体其他端未冻结可用余额清偿，采用人工调整双人复核。此为特定清偿权限，不是各端钱包日常自动混用。

## 9. 订阅、月费与停用

订阅按“真实主体＋使用端”归属。主商户和独立主体分销商分别订阅商户端；同主体内部渠道纳入本主体商户端订阅。工厂端、创作者中心分别订阅，员工不单独订阅。

月费预付，可从对应端未冻结可用余额自动扣缴，不使用生产信用额度。记录计划版本、期间、金额与流水；到期前提醒，自动扣款失败通知主账号及有订阅、账务管理权的相关账号。

到期暂停新增业务：不新增提交生产、发布商品或作品、授权等；商户后台继续同步订单，生产流转暂停。已被工厂接收的订单继续履约，保留相关售后、充值、提现及账单；若同时触发信用逾期，未开工暂停规则仍须执行。

同主体内部渠道随该主体订阅暂停；独立主体分销商自身订阅有效时，可依既有有效合作和授权继续业务，主商户对应收益照常按结算规则处理。信用限制另行校验。

欠费停用期间继续按原账期累计月费，正式终止订阅生效后才停止新增月费，历史欠费仍需补缴。充值或收入入账后，用该端未冻结可用余额优先从早到晚补缴，允许部分补缴；截至当前账期月费全部结清后恢复新增业务，其他限制仍独立生效。

升级补当前周期剩余服务期间月费差额后立即生效；降级或关闭自动续费到当前付费周期结束后执行。已锁定价格及服务费规则不重算。具体套餐价格、比例和完整周期细则仍待细化。

## 10. 取消、退款与补发

销售平台取消不等于 Nexus 自动取消或自动退款。尚未开工的对应订单先暂停并通知所属账号处理。

未开工取消按主控配置处理；工厂已接单则先算应收取消费用，释放剩余冻结与对应库存预留。费用条件、金额及分配尚未细化。开工后商户不能自行改 SKU、数量或取消，交主控客服处理；主控全局停用 SKU 和异常改派保留专门处理权限，不能抹除已发生记录。

售后须关联原订单、包裹、SKU 和申请数量，未签收的丢失、破损等也可申请。当前处理方式为退款和补发，同案件可按批准数量拆分处理，不得重复超量。质保、运输损坏、运输丢件、错发分别配置规则，期限及凭证细节待设计。

**补发先协商，争议再仲裁：**

1. 商户或分销商向工厂提出补发需求。
2. 工厂在补发需求单填写金额，双方确认后履行。
3. 未达成一致，商家主动提交争议与资料。
4. 主控客服依据双方资料裁决，结果有约束力，无须双方再次同意。

补发金额以双方确认或仲裁结果为准，不一律机械套原工厂单价；不重复收版权费、不再次产生主商户分销差额。允许零元补发，此时工厂本次商品结算收入也为零，仍保留全部履约记录。系统服务费细则另行确定。

退款由主控审批并核定各方金额，可形成负余额，但须遵守后续确认的信用上限限制；不能沿用早期“可无限扣成负数继续执行”的理解。

异常改派可由主控全单或部分执行，包含已开工数量。原厂投入、转运或作废、新厂履约分别留记录。全单取消或改派后立即撤销原厂继续访问随单素材的权限；部分改派只保留继续承担部分所必需的访问范围。

## 11. 沟通、通知和系统维护

商户、分销商与工厂可以围绕订单和设计直接留言，主控客服按权限介入；原文保留，可提供中、英、西语翻译。留言不替代正式取消、变更、费用确认或退款流程。

首期通知使用邮件、网页消息及业务待办，App 通知随后续 App 开发。匹配失败、权限失效、扣款失败、资金不足和超期等按相应规则通知。

主控可开启全局维护，四端、API 和后台任务暂停业务执行；外部回调暂存，恢复后校验处理。履约期限、信用账期等自然时间继续计算，不自动顺延，维护影响单独记录。

常见暂停原因及处理入口：

| 原因 | 处理人及恢复条件 |
|---|---|
| 商品未对应、定制资料不完整 | 所属商户或分销商补齐并重新校验整单 |
| 图片不合格 | 所属账号按限定更正流程处理，保留证据与版本 |
| 授权未覆盖 | 获得覆盖接收主体和账号的有效作品授权 |
| 工厂提价未确认 | 普通订单商户确认，分销订单主商户确认 |
| 现金或信用不足 | 补足资金或经主控调整额度，重新校验 |
| 信用逾期 | 还清适用欠款，重新检查与排产 |
| 月费欠缴 | 补清截至当前账期的应缴月费 |
| 超期订单待继续履行确认 | 所属账号授权人员网页确认 |
| 模板或生产文件异常 | 对应责任方处理，文件合格后恢复 |
| 无符合包裹、面单费用条件的分配方案 | 所属账号处理条件，不强制追加费用 |

如存在多个限制，须分别解除，不能用充值、重新订阅或单项授权绕过其他条件。
